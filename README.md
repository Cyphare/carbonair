# CARBONAIR

CarbonAir adalah aplikasi desktop yang menampilkan data kualitas udara, menyediakan pencatatan konsumsi energi harian yang langsung dihitung menjadi emisi karbon dan disimpan ke database lokal, serta menyajikan visualisasi data ringkas beserta sistem notifikasi bahaya polusi di desktop.
