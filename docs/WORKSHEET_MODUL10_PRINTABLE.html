1. FINALISASI APLIKASI & INTEGRASI LAYANAN WEB REST API

Aplikasi desktop CarbonAir telah difinalisasi dari prototipe awal menjadi Minimum Viable Product (MVP v1.0) siap pakai dengan arsitektur berorientasi objek (Encapsulation, Inheritance, Polymorphism), penyimpanan data ganda (SQLite otomatis & PostgreSQL server), serta integrasi langsung layanan pihak ketiga Open-Meteo Web REST API:

  • Open-Meteo Air Quality REST API (https://air-quality-api.open-meteo.com/v1/air-quality): Mengambil US AQI real-time, kadar polutan PM2.5, PM10, CO, NO₂, O₃, grafik tren AQI 24 jam per jam, serta pemantauan serentak (batch) 12 kota Indonesia pada Peta AQI interaktif.
  • Open-Meteo Weather REST API (https://api.open-meteo.com/v1/forecast): Mengambil suhu udara, kecepatan angin, dan kelembapan secara paralel.
  • Open-Meteo Geocoding REST API (https://geocoding-api.open-meteo.com/v1/search): Pencarian kota kustom secara langsung dari Dashboard.
  • Layanan Inti & Nilai Tambah MVP: Registrasi akun baru, manajemen profil & ubah password, CRUD penuh Log Energi & Emisi (Tambah, Edit, Hapus, Filter Listrik/BBM, Ekspor CSV), Rekomendasi Cerdas berbasis AQI & emisi, serta Notifikasi Toast Peringatan Bahaya Polusi di Desktop.
2. PENGEMASAN, INSTALASI & KONFIGURASI BASIS DATA
  1. Paket Aplikasi Mandiri (.exe): Aplikasi dikemas dalam folder rilis CarbonAir-v1.0-win-x64 berisi CarbonAir.exe (self-contained single-file), appsettings.json, setup.bat, database/, dan docs/.
  2. Zero-Config SQLite (Default): Cukup ekstrak ZIP dan klik dua kali CarbonAir.exe (atau jalankan setup.bat pilihan 1). File carbonair.db beserta tabel users, emission_logs, akun demo (user1/user1 Admin, user2/user2 Regular), dan data sampel otomatis dibuat.
  3. Mode PostgreSQL (Opsional Server): Klik tombol Konfigurasi DB pada layar Login atau Pengaturan → Atur Database... (atau setup.bat pilihan 2), pilih PostgreSQL (Server), masukkan Host/Port/Database/Username/Password, klik Tes Koneksi, lalu Simpan & Terapkan.
3. PANDUAN SINGKAT PENGGUNAAN APLIKASI
Halaman / Menu Alur Penggunaan Utama
Login & Daftar Masuk memakai akun demo (user1/user1 atau user2/user2), buat akun baru lewat Daftar di sini, atau ubah konfigurasi database lewat Konfigurasi DB.
Dashboard Pilih kota preset atau cari kota baru lewat API; amati KPI AQI, total emisi, cuaca/angin, grafik tren 24 jam dinamis, konsentrasi 5 polutan, dan rekomendasi cerdas.
Peta AQI Lihat status 12 stasiun kota di peta Indonesia berkode warna EPA; klik salah satu pin kota untuk melihat detail dan tekan Pantau di Dashboard.
Log Energi Pilih Listrik (0.85 kg/kWh) atau BBM (2.30 kg/L), masukkan jumlah (estimasi CO₂ tampil langsung) & tanggal, simpan, edit/hapus riwayat, saring, atau ekspor ke .csv.
Pengaturan Ubah email, kota default, password, satuan emisi (kg/ton), interval auto-refresh API, tes koneksi REST API, dan uji/atur ambang batas notifikasi polusi desktop.
